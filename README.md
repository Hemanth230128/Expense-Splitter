# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## AI Quick Add setup

`Quick AI Add` uses Google Gemini via Genkit.

1. Copy `.env.example` to `.env.local`
2. Set `GOOGLE_API_KEY` (or `GEMINI_API_KEY`) with your Google AI Studio key
3. (Optional) set `GEMINI_MODEL=googleai/gemini-2.0-flash`
4. Restart `next dev`
