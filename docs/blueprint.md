# **App Name**: SplitWisePro

## Core Features:

- User Account Management: Enable secure user sign-up, login via email, and management of user profiles.
- Group Creation & Member Invites: Allow users to create new groups and invite other users by email to join.
- Detailed Expense Entry: Users can add new expenses, specifying description, total amount, who paid, and involved group members, with options for equal splits or custom amounts per member.
- Dynamic Group Dashboard: Display a clear overview of each group's financial status, including member balances, individual debt amounts, and a sortable expense history.
- Intelligent Expense Parsing: Provide a tool for users to add expenses by interpreting natural language descriptions (e.g., 'Bob paid $50 for dinner for Alice, Charlie, and himself.').
- Optimal Debt Simplification: Implement a robust algorithm to calculate and suggest the minimum number of transactions required to settle all outstanding debts within a group.
- Settlement Confirmation: Allow users to easily record and confirm partial or full debt settlements between members, updating group balances accordingly.

## Style Guidelines:

- Primary color: A vibrant yet calming blue (#85B9E0) that evokes reliability and clarity, standing out effectively against the dark background.
- Background color: A deep, muted charcoal blue (#20262C) for a consistent dark theme, ensuring readability and focus.
- Accent color: A striking aqua (#3DCBEA) to highlight key actions, interactive elements, and draw attention to important information, providing good contrast.
- Body and headline font: 'Inter' (sans-serif) for its modern, highly legible, and objective aesthetic, suitable for numerical data and extensive text across the application.
- Utilize a consistent set of clean, minimalist line icons that maintain a modern and professional appearance throughout the dark interface.
- Adopt a clean, spacious layout with card-based elements for grouping related information like expenses and group members, enhancing organization and scannability on all screen sizes.
- Incorporate subtle, non-intrusive transitions and micro-interactions (e.g., button hovers, form submissions) to provide positive user feedback and a fluid experience.
